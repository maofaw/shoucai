# 三角洲收菜助手

低频读取 moligod 特勤处公开市场快照，生成制造、买料和预计利润建议。公开网页部署在 [三角洲收菜助手](https://maofaw.github.io/shoucai/)；构建任务按计划运行，平时不占用本机内存。

项目同时包含手机优先的静态看板：

```powershell
npm run serve:web
```

浏览器打开 `http://127.0.0.1:4173`。网页目录为 `web/`，GitHub Pages 工作流位于 `.github/workflows/pages.yml`。

网页打开先显示月保守预计，以及未来7天保守和较高两档预计到手利润，再显示下次收菜、买料结论和四台制造建议。月保守预计按周保守预计乘以4.33换算，属于保守估算而非收益保证。清仓页会按最近4个周末的成品小时价，比较周六、周日连续2小时窗口，并给出首选、备选和样本可信度；这能覆盖28个号约112分钟的清仓过程，样本不足时才沿用周六21:30。买料页会自动省略“一周成本占比不高于3%、30天价格常见波动不高于8%”的便宜稳定材料；这些材料仍计入利润与预算，只是不占用重点清单。设置页可改总账号数、分成账号数、本人分成比例、哈夫币兑换人民币比例和单号买料预算；修改预算后，自动购买天数和7天预算缺口会在当前设备即时重算。普通链接可点击“本轮已完成”，按实际完成时间显示8小时后的下一次收菜；时间只保存在当前浏览器，不会跨设备同步。历史行情证据不足时，页面会标明“临时估算”或“本周没有可靠的首选时段”，不承诺收益。

高级燃料和钛合金都不能直接购买，只能兑换：1个盒装挂耳咖啡＋1个海盗弯刀兑换4个高级燃料；1个可编程处理器＋1个清新橘味能量凝胶兑换4个钛合金。Moligod 对这两种目标材料显示的是折算后的单个兑换成本；本站会把采购清单展开成真正需要购买的兑换材料。当前临时主选与稳定基准不同时，稳定基准的独有材料仍列在“稳定方案备料”，用于继续盯价，但不计入当前生产预算；例如制药台暂时不造精密护甲维修包时，仍会监控特种钢和无线便携电钻。

公开网站构建只读取 `config.site.json`。本机运营配置 `config.json`、SQLite、日志、报告和 Obsidian 笔记均被 `.gitignore` 排除，不会上传到公开仓库。低价买料通知代码已经接入每2小时构建流程：只有单项材料进入7/14/30天囤货档才会提交给通知服务，同材料冷却24小时，档位升级可突破冷却，便宜稳定材料保持静默。Cloudflare Worker、D1和飞书密钥仍需完成首次部署后才会真正发消息。

## 默认运行时间

- 06:50：为07:00收菜生成建议。
- 14:50：为15:00收菜生成建议。
- 22:50：为23:00收菜和周末出售生成建议。
- 本机旧版周六提醒仍以21:30为兜底；实际清仓请以网页“清仓”页的动态首选窗口为准。

06:50、14:50、22:50的通知直接显示收菜时间、四个制造台配方、囤料结论和“当前行情理论利润”。宿舍00:00至06:30断电，因此不安排凌晨本机任务，避免通电后补跑造成重复提醒。

## 使用

```powershell
npm test
npm run run
npm run task:install
```

生成内容：

- `data/market.sqlite`：本地行情历史；SQLite是文件，不是后台服务。
- `reports/latest.md`：最近一次建议。
- `logs/advisor.log`：运行结果与错误。
- Obsidian：`D:\我的笔记\200-Projects\三角洲收菜运营\三角洲收菜实时建议.md`。

## 重要配置

编辑 `config.json`：

- `historicalStock.enabled`：仅用于本机旧版运营报告；公开网站不按既有库存核算。
- `balancePerAccount`：单号可用哈夫币变化时更新。
- `haffPerCny`：现实租赁比例变化时更新。
- `switchThreshold`：默认新配方的保守整周预计净利润高出5%才建议下一轮切换；H09另有稳定性门槛。
- `switchBasis`：当前固定为 `weeklyProjectedProfit`，按一周生产量比较，不按单轮或单日利润比较。

## 卸载计划任务

```powershell
npm run task:remove
```

删除计划任务不会删除行情数据库或报告。
